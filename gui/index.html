// Modules

Nine categories. Every layer covered.

From cloud misconfigurations to kernel parameters, each module runs independently or as part of a full scan.

☁

Cloud Security

Audit AWS, Azure and GCP for public storage, open security groups, missing CloudTrail, unencrypted EBS, IAM misconfigurations, and network exposure.

cloud_audit cloud_iam cloud_network
🔒

System Hardening

Verify filesystem partitions, SSH config, kernel sysctl parameters, unnecessary services, boot security, and CIS-aligned system configurations.

harden_linux harden_ssh harden_kernel harden_services
🌐

Network Analysis

Scan hosts, audit firewall rules, test DNS security (DNSSEC, SPF, DMARC, CAA), and verify TLS certificates, protocols, and cipher suites.

net_scan net_firewall net_dns net_tls
🐛

Vulnerability Assessment

Find missing patches, SUID/SGID binaries, world-writable files, web security headers, server disclosure, and dependency vulnerabilities via npm/pip audit.

vuln_system vuln_web vuln_deps
📜

Compliance Audit

Map controls against CIS v8, ISO 27001 Annex A, and PCI DSS requirements. Validate password policies and account lockout settings.

comply_cis comply_iso27001 comply_pci comply_password
📑

Log Analysis

Parse authentication logs for brute-force attempts, track sudo usage, surface critical syslog events, and query the audit subsystem for suspicious activity.

log_auth log_syslog log_audit
🚨

Incident Response

Capture full system snapshots, detect processes running from deleted binaries, flag unusual outbound connections, and hunt persistence mechanisms.

ir_snapshot ir_processes ir_connections ir_persistence
📦

Container Security

Audit Docker daemon configuration, detect privileged containers, scan images with Trivy, and review Kubernetes RBAC bindings and network policies.

container_docker container_k8s container_images
💻

Asset Inventory

Collect system info, hardware details, network interfaces, installed packages, running services, listening ports, and established connections.

asset_inventory asset_ports report_gen
// Architecture

Clean module structure

Every module is a standalone bash script. Source one, source all, or run the interactive menu.

// Features

Built for real-world defense

⚡

Zero Dependencies

Pure bash. Uses coreutils and standard Linux tools already on your system. No Python, no Ruby, no package managers.

🛠

Modular Architecture

Run a single module, a category, or everything. Each script sources independently and writes its own report file.

📊

HTML Report Generation

Consolidates all findings into a styled, self-contained HTML report you can share with your team or attach to a ticket.

🔍

Multi-Cloud Support

Audits AWS, Azure, and GCP using their native CLIs. Detects which providers are configured and runs the relevant checks.

📄

Compliance Mapping

Checks mapped to CIS Controls v8, ISO 27001 Annex A, and PCI DSS requirements. Know where you stand before the auditor arrives.

🔌

CLI & Interactive

Full interactive menu with submenus, or invoke any module directly with flags: -o json -f report.txt -v
